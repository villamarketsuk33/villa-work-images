# Image brief

Created with the built-in image generation tool for the Villa Market LINE work menu.
Style: matching friendly 3D clay illustrations, navy and crimson uniforms, bright supermarket backgrounds, wide 3:1 composition, no in-image text.

- villa-fondue: employee reports a store problem with a phone, alert map pin and checklist.
- work-points-lotto: checked tasks, gold reward medal, tokens and reward ticket.
- repair-maintenance: maintenance technician, toolbox, wrench and air conditioner.
- product-details-scanner: phone scans the barcode on a grocery item.
- morningwalk-submission: two employees inspect a store in the morning with a checklist.
- daily-summary: laptop report dashboard, calendar, clock and paper report.

The source illustrations are preserved in originals. GitHub Actions runs build_images.py to create the public images used by LINE.
